# 📓 내 일기장

사용자 로그인 기능과 일기 저장/관리 기능이 있는 간단하고 아름다운 일기장 웹사이트입니다.

## ✨ 주요 기능

- 🔐 **사용자 인증**
  - 회원가입 및 로그인
  - 비밀번호 확인 기능
  - 로그아웃

- 📝 **일기 관리**
  - 일기 제목, 내용, 날짜 입력
  - 작성한 일기 목록 조회
  - 일기 삭제 기능
  - 최신 일기부터 표시

- 💾 **데이터 저장**
  - LocalStorage를 사용한 브라우저 로컬 저장
  - 새로고침해도 데이터 유지
  - 별도의 서버 없이 작동

- 🎨 **반응형 디자인**
  - 모바일, 태블릿, 데스크톱 대응
  - 그라디언트를 사용한 현대적 디자인
  - 부드러운 애니메이션 효과

## 🚀 시작하기

### 필수 요구사항
- 웹 브라우저 (Chrome, Firefox, Safari, Edge 등)
- 인터넷 연결 없이도 사용 가능

### 사용 방법

1. **저장소 클론**
```bash
git clone https://github.com/hwani731-art/diary-website.git
cd diary-website
```

2. **파일 열기**
   - `index.html`을 웹 브라우저에서 직접 열기
   - 또는 로컬 웹 서버 사용:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

3. **회원가입**
   - "회원가입" 링크 클릭
   - 아이디, 비밀번호 입력 후 회원가입 버튼 클릭

4. **로그인**
   - 가입한 아이디와 비밀번호로 로그인

5. **일기 작성**
   - 제목, 내용, 날짜 입력
   - "저장하기" 버튼 클릭
   - 저장된 일기는 우측 목록에 표시

6. **일기 관리**
   - 일기 목록에서 삭제 버튼으로 일기 제거
   - 로그아웃 버튼으로 계정 전환

## 🛠️ 기술 스택

- **HTML5** - 구조
- **CSS3** - 스타일링 (Flexbox, Grid, 그라디언트)
- **Vanilla JavaScript** - 기능 구현
- **LocalStorage API** - 데이터 저장

## 💡 주요 기능 설명

### 사용자 데이터 저장
- 모든 사용자 정보와 일기는 브라우저의 LocalStorage에 저장됩니다
- 브라우저를 닫아도 데이터가 유지됩니다
- 브라우저 캐시를 삭제하면 데이터가 삭제됩니다

### 보안
- 비밀번호는 일반 텍스트로 저장됩니다 (로컬 저장이므로)
- XSS 공격 방지를 위해 HTML 이스케이프 처리됨
- 실제 서비스에서는 백엔드 암호화 권장

### 반응형 디자인
- 768px 이하에서는 단일 컬럼 레이아웃으로 변경
- 모바일 친화적 터치 인터페이스
